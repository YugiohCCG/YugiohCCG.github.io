# Ohmen / Ohmenchanic — official TCG wording audit

Only official Konami English TCG card-text pages are used below. OCG/Asian-English pages, fan translations and community rulings are not used as authority.

**Result: two editorial reductions across two cards, saving 39 characters. No game scripts, statistics, arrows, costs, targeting, timing, thresholds or use/activation limits are changed.**

The references support the identified wording or operation only. None is claimed to have an identical complete custom-card effect. Equivalence of the two edited clauses is the audit conclusion, not an official ruling on these custom cards. All other clauses remain exactly as in the latest corrected cards.

## Accepted reductions

- Volt Link 1+: omit “removed” after “for each” (8 characters). Fire Cracker uses the same 300-damage-per-counter shorthand; Volt's cost and timing remain untouched.
- Carcel Link: use “its co-linked monsters” for the same defined group, following Transcode Talker's group wording (31 characters). Combined Link Ratings and all recipients are unchanged.
