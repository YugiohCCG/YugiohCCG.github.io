### Semantic Effect Audit Report: Batch 11

| Passcode | Card Name | Clause | Issue Type | Line | Description | Proposed Fix |
|---|---|---|---|---|---|---|
| `243420199` | Shining Brigade - Melody Division | *"During your Main Phase, you can Normal Summon/Set 1 "Shining Brigade" monster in addition to your Normal Summon/Set (You can only gain this effect once per turn)."* | **Confirmed** | 8, 10 | Implemented as an Ignition effect (`EFFECT_TYPE_IGNITION`) that applies a flag, rather than a continuous unclassified field effect. | Change `SetType` to `EFFECT_TYPE_FIELD`, Code to `EFFECT_EXTRA_SUMMON_COUNT`, Range to `LOCATION_MZONE`, and TargetRange to `(LOCATION_HAND+LOCATION_MZONE, 0)`. |
| `236616849` | Shining Brigade - Revenge Division | *"If a "Shining Brigade" card you control leaves the field because of your opponent's card:"* | **Confirmed** | 47 | `cfilter` checks `c:IsReason(REASON_EFFECT) and c:GetReasonPlayer()==1-tp`, which fails to trigger if destroyed by an opponent's battle. | Add `or (c:IsReason(REASON_BATTLE) and Duel.GetAttacker():IsControler(1-tp))` |
| `236616849` | Shining Brigade - Revenge Division | *"Attach 1 "Shining Brigade" card from your Deck to this card as material."* | **Confirmed** | 80 | The mandatory trigger (`TRIGGER_F`) returns `false` in `s.atttg` if the Deck has no targets. This improperly prevents activation. | Change to `if chk==0 then return true end`. |
| `223750159` | Shining Brigade Armada | *"If this card is destroyed... Special Summon... up to the number of cards your opponent controls..."* | **Confirmed** | 58 | Mandatory trigger returns `false` at `chk==0` if the opponent controls 0 cards, preventing the mandatory activation. | Change to `if chk==0 then return true end`. |
| `244986323` | Shining Brigade Origins | *"...destroy 1 card your opponent controls, then banish 1 card in either player's GY."* | **Ambiguous** | 100 | The script requires a target in the GY at activation time. While this matches OCG rulings for "then" conjunctions, it restricts resolving if the destroyed card would be the only card in the GY. | No strict fix, but flag for live-testing. |
| `232824319` | Shining Brigade - Companion Team | *"Once per turn, when a monster on the field declares an attack: Special Summon..."* | **Confirmed** | 50 | Another instance of a mandatory trigger returning `false` on `chk==0` if there are no targets. | Change to `if chk==0 then return true end`. |
| `241504188` | Shining Brigade - Absolute Supremacy | *"When your opponent activates a monster effect or a Spell/Trap Card..."* | **Confirmed** | 36 | `negcon` does not differentiate between Spell/Trap Card activations and effect activations. It wrongly negates Spell/Trap *effects* in the GY. | Add `and (re:IsActiveType(TYPE_MONSTER) or re:IsHasType(EFFECT_TYPE_ACTIVATE))` |
| `238841732` | Let's Go, Shining Brigade! | *"You can only activate 1 'Let's Go, Shining Brigade!' effect per turn, and only once that turn."* | **Suspected** | 11, 23 | Both effects use `id+EFFECT_COUNT_CODE_OATH`. This merges their counts, but modern EDOPRo convention prefers `(1, id)` for shared counts. | Use standard `(1, id)` format. |
| `226827770` | The One Called Forth | *"...an effect that Summons a monster with that name..."* | **Suspected** | 76 | `s.efilter` checks `aux.IsCodeListed`. This is overly broad and protects effects that simply search or send the declared card to the GY. | Flag for live-test and verify if checking `CATEGORY_SPECIAL_SUMMON` is sufficient. |
| `215142357` | Shining Brigade - Stand Together! | *"...attach 1 "Shining Brigade" monster from your hand or GY as material."* | **Confirmed** | 69 | `s.attfilter` only checks `IsSetCard`. It incorrectly allows players to attach "Shining Brigade" Spells/Traps. | Add `and c:IsType(TYPE_MONSTER)`. |
| `237692523` | Pixie Bot | *"...to your zone a Link Monster points to."* | **Confirmed** | 61 | `s.linkedzone` calls `GetMatchingGroup` with `LOCATION_MZONE, 0`. It fails to account for opponent's Link Monsters pointing to your zones. | Change location scope to `LOCATION_MZONE, LOCATION_MZONE`. |
| `249629457` | Shining Brigade - Last Stand | *"You can only use each effect... once per turn."* | **Confirmed** | 18, 31 | Effects register counts with `id` and `id+100`. In modern formats, this creates unrelated limits. | Update to `{id, 1}` and `{id, 2}` to enforce proper HOPT. |
| `234507067` | Chrono-Saur Brachio | *"You can only use each effect of "Chrono-Saur Brachio" once per turn."* | **Confirmed** | 7 | The unclassified Special Summon procedure (`e1`) lacks a count limit completely, allowing infinite summons. | Register `e1:SetCountLimit(1, id)`. |
| `235637994` | Chrono-Saur Dactylus | *"...if a "Chrono-Saur" card or a Dinosaur monster in your hand or field was destroyed..."* | **Confirmed** | 57 | `s.checkop` relies on `tc:GetPreviousRaceOnField()`, which returns 0 for a Dinosaur monster destroyed in the hand. | Check `tc:GetOriginalRace()` for cards originating from the hand. |
| `251236672` | Chrono-Saur Laplace Plesio | *"You can only use the previous effects of [Name] once per turn."* | **Confirmed** | 11, 23 | The first and second effects share exactly `id`, meaning only 1 can be used per turn. They should be independent HOPTs. | Update limits to `{id, 1}` and `{id, 2}`. |
| `259366507` | Aquila, Zephorion's Predictor | *"You can only Special Summon [Name] once per turn this way."* | **Confirmed** | 8 | The unclassified Special Summon procedure (`e1`) lacks `SetCountLimit(1, id, EFFECT_COUNT_CODE_OATH)`, ignoring the HOPT entirely. | Add `e1:SetCountLimit(1, id, EFFECT_COUNT_CODE_OATH)`. |
| `257081514` | Auriga of the Eldoran Empire | *"You can only Special Summon [Name] once per turn this way."* | **Confirmed** | 8 | Same issue as Aquila; the unclassified procedure lacks a count limit. | Add `e1:SetCountLimit(1, id, EFFECT_COUNT_CODE_OATH)`. |
| `213990492` | Eridani, Squire of Zephorion Prime | *"If "Eldora..." is in your GY, your opponent cannot declare an attack."* | **Confirmed** | 22 | Effect is incorrectly registered with `SetRange(LOCATION_GRAVE)`. The continuous effect text lacks "While this card is in your GY", so it should only apply while face-up on the field. | Change range to `LOCATION_MZONE`. |
| `244972185` | The Spires of Zephorion Prime | *"(This card is always treated as an "Eldora" card.)"* | **Confirmed** | N/A | The script completely lacks an `EFFECT_ADD_SETCODE` property. It will not be searchable as an "Eldora" card from the Deck or GY. | Add a global/unclassified `EFFECT_ADD_SETCODE` mapped to `0x0738`. |
