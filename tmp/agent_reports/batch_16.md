# Batch 16 Audit Report

I have audited all 25 cards in `batch_16.json` against their official English text and Lua implementations. Below is the clause-by-clause breakdown and identified issues.

### Confirmed Issues
**1. Hardcoded IDs for "Hallo" and "Ween" Monsters**
The card texts for the "Hallo-Ween!" archetype frequently refer to a `"Hallo" monster` or `"Ween" monster`. In Yu-Gi-Oh! PSCT, specifying a quoted string followed by "monster" indicates a name substring match (pseudo-archetype). However, the scripts hardcode the specific passcodes for existing cards instead of implementing a substring check or assigning a sub-setcode.
- **Affected Cards**:
  - `c230749983.lua` (Hallo, the Giver of Tricks): Hardcodes `250262550` for `"Ween" monster`.
  - `c250262550.lua` (Ween, Guidance to Treats): Hardcodes `230749983, 231331942` for `"Hallo" monster`.
  - `c224800873.lua` (Hallo-Ween! Basket of Treats): Hardcodes IDs for both.
  - `c255977900.lua` (Happy Hallo-Ween!): Hardcodes IDs for both.
  - `c215621622.lua` (A Night of Fright on Hallo-Ween!): Hardcodes ID for `"Ween" monster`.
- **Proposed Fix**: Implement a name substring check (e.g., using `string.find(c:GetOriginalName(), "Ween")` if supported) or assign internal setcodes for "Hallo" and "Ween" to maintain forward compatibility when new cards are added.
