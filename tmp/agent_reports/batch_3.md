# Yu-Gi-Oh! CCG Semantic Effect Audit Report — Batch 3

I have completed the audit of the 25 cards in batch 3. I cross-referenced the English text from `src/data/cards.json` with the Lua scripts in `public/CCG Downloads/CCG_Scripts/c<passcode>.lua`. 

Here are the findings formatted in a clause-by-clause Markdown table:

| Card | Passcode | Clause | Issue Type | Findings | Proposed Fix |
|---|---|---|---|---|---|
| The Hanging Frute | 213266433 | `"Frute" monsters you control can attack all face-down Defense Position monsters your opponent controls, once each.` | Live-Test Only | The Lua uses `EVENT_ATTACK_ANNOUNCE` to dynamically add `EFFECT_EXTRA_ATTACK_MONSTER` based on the current count of face-down monsters. This may fail to give the correct number of attacks if the opponent summons a new face-down monster during the Battle Phase. | Consider testing edge cases or using `EFFECT_ATTACK_ALL` with a custom value function that filters for face-down defense position monsters. |
| NiuHao - Koai | 231825514 | `...shuffle them into the deck, then banish "Sacred Treasure" Spells from your Deck up to the number of monsters shuffled by this effect.` | Suspected | The banish is prompted with `Duel.SelectYesNo` (Line 78), making it optional. The English text lacks "you can" after "then", meaning it should be mandatory to banish 1 to `ct` cards if possible. | Remove the `Duel.SelectYesNo` check and make the `Duel.SelectMatchingCard` mandatory if targets exist. |
| NiuHao - Zao | 250556612 | `...then, immediately after this effect resolves, apply the banished cards activation effects in sequence.` | Ambiguous | The effect applies the spells' effects inline during the resolution of this effect (Lines 75-80), rather than applying them truly "immediately after this effect resolves" (e.g. in a new chain link or separately). | If intended to be a separate resolution step outside the current chain link, it may need to be scheduled via a delayed event. |
| Domestica Praerie | 259264881 | `Except during the Battle Phase, this card cannot be Summoned while you control a monster, except by Tribute Summon where the required Tribute(s) are the only monster(s) you control.` | Confirmed | `EFFECT_CANNOT_SUMMON` condition strictly checks `Duel.GetFieldGroupCount(...)>0` (Line 27). This strictly prevents even attempting a Tribute Summon if you control 1 monster, meaning the "except by Tribute Summon" clause is never reachable. | Use an `EFFECT_LIMIT_SUMMON_PROC` or modify the condition to evaluate if the tribute procedure will leave the field empty. |
| Domestica Anjelie | 259337739 | `Except during the Battle Phase, this card cannot be Summoned while you control a monster, except by Tribute Summon where the required Tribute(s) are the only monster(s) you control.` | Confirmed | Same as above. `EFFECT_CANNOT_SUMMON` condition blocks Tribute Summons if you control a monster. | Implement logic to evaluate the post-tribute board state or use a custom summon procedure. |
| Domestica Lunalie | 259245149 | `Except during the Battle Phase, this card cannot be Summoned while you control a monster, except by Tribute Summon where the required Tribute(s) are the only monster(s) you control.` | Confirmed | Same as above. `EFFECT_CANNOT_SUMMON` condition blocks Tribute Summons if you control a monster. | Implement logic to evaluate the post-tribute board state or use a custom summon procedure. |

The remaining 19 cards were found to accurately match their English text requirements.
